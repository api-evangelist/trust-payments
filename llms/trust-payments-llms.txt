# Trust Payments

> Trust Payments (formerly Secure Trading / SecureTrading) is a London-headquartered payment gateway and processor operating across the UK, Europe, and the US. It offers online, in-store POS, unattended, and mobile card acceptance, acquiring, alternative/local payment methods, tokenisation, recurring billing, payouts, and 3-D Secure authentication through its TRU Connect gateway. The developer surface is the Secure Trading Payment Platform (STPP) - a server-to-server JSON Webservices API (AUTH, ACCOUNTCHECK, REFUND, SUBSCRIPTION, TRANSACTIONUPDATE, TRANSACTIONQUERY) - plus a JWT-authenticated client-side JavaScript Library (ST.js) for PCI-reduced hosted card fields, and mobile SDKs. No downloadable OpenAPI is published; production access requires PCI certification, account approval, and credential exchange.

## APIs

- [Webservices API (STPP JSON)](https://help.trustpayments.com/hc/en-us/sections/360005821218-Webservices-API): Server-to-server JSON API for card processing on the TRU Connect gateway. baseURL https://webservices.securetrading.net/json/
- [Payouts API](https://help.trustpayments.com/hc/en-us/articles/4402771924497-Payouts-with-Webservices-API): Disbursement/payout flows over the Webservices API.
- [JavaScript Library (ST.js)](https://help.trustpayments.com/hc/en-us/articles/4402754655761--Install-our-library): Client-side hosted card fields + tokenisation, authorised by a server-generated JWT.
